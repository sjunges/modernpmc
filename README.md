# Modern PMC
## Lecture Notes on Probabilistic Model Checking for MDPs
These lecture notes are written for the course Model Checking at Radboud University and cover part of the material.
The notes are available at [sjunges.github.io/modernpmc](https://sjunges.github.io/modernpmc/) and are currently in alpha state.
