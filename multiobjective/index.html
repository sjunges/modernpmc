1.1What are Multiobjective Model Checking queries?discuss!¶

Throughout this chapter, we fix an MDP M\mdpM with nnn target sets T1,…,TnT_1, \dots, T_nT1​,…,Tn​, Ti⊆ST_i \subseteq STi​⊆S. The central multiobjective model checking problem is the following:

Definition 1 (Multiobjective Model Checking Achievability Query)

Fix an MDP M\mdpM with mmm target sets T1,…,TmT_1, \dots, T_mT1​,…,Tm​, Ti⊆ST_i \subseteq STi​⊆S. A policy π\piπ achieves a point λ⃗\vec{\lambda}λ, if

⋀i≤mPrπ(◊Ti)≥λi.\bigland_{i \leq m} \pr_\pi(\lozenge T_i) \geq \lambda_i.i≤m⋀​Prπ​(◊Ti​)≥λi​.

We call π\piπ a witnessing policy for λ⃗\vec{\lambda}λ. A point λ⃗∈Rm\vec{\lambda} \in \mathbb{R}^mλ∈Rm is achievable if there exists a witnessing policy, i.e., λ⃗\vec{\lambda}λ is achievable if

∃π∈Π.⋀i≤mPrπ(◊Ti)≥λi.\exists \pi \in \Policies. \bigland_{i \leq m} \pr_\pi(\lozenge T_i) \geq \lambda_i.∃π∈Π.i≤m⋀​Prπ​(◊Ti​)≥λi​.

We denote the set of achievable points with AchM(T1,…,Tm)\Ach_\mdp(T_1, \dots, T_m)AchM​(T1​,…,Tm​).

We simply write Ach\AchAch whenever M\mdpM and T1,…,TmT_1, \dots, T_mT1​,…,Tm​ is clear from the context.

Example 2

Continuing the example above, the policy π\piπ with π(s0)=γ\pi(s_0) = γπ(s0​)=γ and π(s4)=α\pi(s_4) = απ(s4​)=α witnesses the achievability of (0.5,0.35)(0.5, 0.35)(0.5,0.35). While we can reach the red states with probability 0.9 and the blue states with probability 0.6, the point (0.9,0.6)(0.9, 0.6)(0.9,0.6) is not achievable.

Note that the literature considers a much wider variation of combinations of different objectives, including the combination of minimal and maximal reachability probabilities, the extension to rewards, cost-bounded reachability probabilities, LTL formulas, etc., as well as their combinations.

1.2On witnessing policiesdiscuss!¶

First, deterministic policies are not sufficient:

Lemma 1

There exist MDPs with 2 targets and achievable points such that every witness is randomizing, i.e., where no deterministic witnessing policy exists.

A point λ⃗\vec{\lambda}λ is achievable iff there exists a randomising finite-memory policy that achieves λ⃗\vec{\lambda}λ.

1.3On achievable pointsdiscuss!¶

We can look at the geometric properties of Ach\AchAch. We use notions such as convex and downward closed sets from Section 3.

Theorem 2

The set Ach\AchAch is convex and downward-closed.

Downward closure follows immediately from the definition of achievability. The convex closure is a bit more interesting. Intuitively, the idea is that if we pick two achievable points p⃗1,p⃗2\vec{p}_1, \vec{p}_2p​1​,p​2​, we can take two witnessing policies π1,π2\pi_1, \pi_2π1​,π2​. If we now implement a protocol where we flip a coin with probability ccc, we play like policy π1\pi_1π1​ and with probability 1−c1-c1−c, we play like π2\pi_2π2​. One needs some care to correctly define such convex combinations of policies. Consider, e.g., that π1\pi_1π1​ stays forever in an MEC and π2\pi_2π2​ leaves that MEC. A naive realization of a convex combination of both policies would always leave the MEC. A thorough treatment of this topic can be found, e.g., in Quatmann (2023).

Definition 3

A point p⃗∈Rm\vec{p} \in \mathbb{R}^mp​∈Rm is Pareto-optimal for targets T1,…,TmT_1, \dots, T_mT1​,…,Tm​ iff for all q⃗∈Rm\vec{q} \in \mathbb{R}^mq​∈Rm:

  • p⃗≻q⃗\vec{p} \succ \vec{q}p​≻q​ implies q⃗∈Ach\vec{q} \in \mathrm{Ach}q​∈Ach, and

  • q⃗≻p⃗\vec{q} \succ \vec{p}q​≻p​ implies q⃗∉Ach\vec{q} \notin \mathrm{Ach}q​∈/Ach.

The Pareto curve is the set

Pareto={p⃗∈Rm∣p⃗ is Pareto optimal}.\mathrm{Pareto} = \left\{ \vec{p} \in \mathbb{R}^m \mid \vec{p} \text{ is Pareto optimal} \right\}.Pareto={p​∈Rm∣p​ is Pareto optimal}.
Lemma 3

It holds: Pareto⊆Ach\mathrm{Pareto} \subseteq \AchPareto⊆Ach.

Specifically, this means that any Pareto-optimal point has a witnessing policy.
Note that the lemma above is not true for arbitrary objectives that go beyond maximal reachability probabilities.

Theorem 3

There is a finite set of points PPP, such that Ach\AchAch is the smallest convex and downward-closed set containing PPP.

Even stronger (and key to proving the theorem above), these finite points are achieved by deterministic and (bounded) finite-memory policies. However, note that ∣P∣|P|∣P∣ can be superpolynomial in the size of the MDP, even if there are just 2 objectives.

1.4Computing Achievable Pointsdiscuss!¶

We consider two computational problems. The first is a simple decision problem.

Problem: Decision Problem - Achievability

Given an MDP M\mdpM with mmm target sets T1,…,TmT_1, \dots, T_mT1​,…,Tm​, Ti⊆ST_i \subseteq STi​⊆S, and a point λ⃗∈Rm\vec{\lambda} \in \mathbb{R}^mλ∈Rm. Decide whether λ⃗\vec{\lambda}λ is achievable.

Beyond deciding achievability of individual points, we can aim to compute the Pareto curve (or rather, the achievable points). As the representation of the achievable points can be prohibitively large, we are mostly interested in computing a tight approximation.

Problem: Achievable Point Approximation

Given an MDP M\mdpM with mmm target sets T1,…,TmT_1, \dots, T_mT1​,…,Tm​, Ti⊆ST_i \subseteq STi​⊆S. Compute L,U⊆RmL, U \subseteq \mathbb{R}^mL,U⊆Rm such that:

  • L⊆AchM(T1,…,Tm)⊆UL \subseteq \Ach_\mdp(T_1, \dots, T_m) \subseteq UL⊆AchM​(T1​,…,Tm​)⊆U, and

  • ∥U−L∥≤ε\|U - L\| \leq \varepsilon∥U−L∥≤ε, for any given ε\varepsilonε and suitable measure on sets.

Computing the set of achievable points is a special case where ε=0\varepsilon = 0ε=0. Beyond these queries, one can also try to find particular points on the Pareto curve. This is often called a constrained MDP query.

1.4.1Preprocessing: Goal unfoldingdiscuss!¶

In this preprocessing step, we reduce reasoning about randomising finite memory policies to reasoning about randomising memoryless policies. The key insight used here is that the memory is not used arbitrarily, but simply to track which set of target states has been visited previously. We then move this memory from the policy into the MDP itself.

Definition 4 (Goal unfolding)

Given an MDP M=⟨S,A,δorig⟩\mdp = \langle S, A, \delta_\mathsf{orig} \rangleM=⟨S,A,δorig​⟩ with target states T1,…,TmT_1, \dots, T_mT1​,…,Tm​. We define unfolding(M)\mathsf{unfolding}(\mdp)unfolding(M) as an MDP

⟨S×{0,1}m,A,δunf⟩\langle S \times \{0,1\}^m, A, \delta_{\mathsf{unf}} \rangle⟨S×{0,1}m,A,δunf​⟩


with

δunf((s,b),a,(s′,c))={δorig(s,a,s′)if c=succ(b,s′)0otherwise.\delta_\mathsf{unf}((s,b), a, (s',c)) = \begin{cases} \delta_\mathsf{orig}(s,a,s') & \text{if }c=\mathsf{succ}(b, s') \\ 0 & \text{otherwise.} \end{cases}δunf​((s,b),a,(s′,c))={δorig​(s,a,s′)0​if c=succ(b,s′)otherwise.​

1.4.2Deciding achievability via an LPdiscuss!¶

We assume an unfolded MDP as in Definition 4. We furthermore assume the initial state is not in any TiT_iTi​. We first show that the decision problem, whether a given point is achievable, can be solved with an LP. The (standard) LPs for probabilistic model checking have variables for the probability to reach the target and constraints to encode the action selection. That setup makes it hard to define different reachability probabilities under the same policy. However, we can take a different perspective (in fact, the dual perspective in the linear programming theory) and consider the probability mass flow through the MDP.

Specifically, we define an LP over variables ys,ay_{s,a}ys,a​ for every choice (s,a)(s,a)(s,a). The idea is that ys,ay_{s,a}ys,a​ is to encode the expected number of times that a policy chooses (s,a)(s,a)(s,a). Clearly, this number must be non-negative, i.e.,

for all s∈S,a∈Aen(s):ys,a≥0.\text{for all } s \in S, a \in \EnAct{s}: y_{s,a} \geq 0.for all s∈S,a∈Aen​(s):ys,a​≥0.
Remark 1 (Choice of variables.)

One can rewrite this to use variables ys,a,s′y_{s,a,s'}ys,a,s′​ for every transition s→as′s \xrightarrow{a} s'sa​s′, using the equality ys,a,s′=δ(s,a,s′)ys,ay_{s,a,s'} = \delta(s,a,s')y_{s,a}ys,a,s′​=δ(s,a,s′)ys,a​.

Under this intuition, we can define auxiliary expressions for the expected number of times a state is left (outflow) and the number of times a state is entered (inflow).

fout(s)=∑ays,a+[s=sinit]f_{out}(s) = \sum_{a} y_{s,a} + \indicator{s = \sinit}fout​(s)=a∑​ys,a​+[s=sinit​]

and

fin(s′)=∑s∑aδ(s,a,s′)⋅ys,a.f_{in}(s') = \sum_{s}\sum_{a} \delta(s,a,s') \cdot y_{s,a}.fin​(s′)=s∑​a∑​δ(s,a,s′)⋅ys,a​.

Intuitively, we want to express that the times a state is entered must be equal to the times we leave the state, i.e.,

fin(s)=fout(s).f_{in}(s) = f_{out}(s).fin​(s)=fout​(s).

However, the number of times a state is visited under a particular policy may be infinite, if it is part of a maximal end component. We make the following two key observations (from Forejt et al. (2011)):

  • if there still is a target state that can be reached, a (Pareto) optimal policy has no incentive to stay in an end-component.

  • if there is no target state to be reached, the behavior of a policy (and what states it will reach) is not relevant to our property. We can define the relevant states as follows:

    Srel={(s,b)∣∃c≥b.(s,c) reachable from (s,b).}S_\mathsf{rel} = \{ (s,b) \mid \exists c \geq b. (s,c) \text{ reachable from } (s,b). \}Srel​={(s,b)∣∃c≥b.(s,c) reachable from (s,b).}

    [1] We will therefore formulate the following constraint:

for alls∈Srel,fin(s)=fout(s).\text{for all} s \in S_\mathsf{rel}, f_{in}(s) = f_{out}(s).for alls∈Srel​,fin​(s)=fout​(s).

The last remaining set of constraints enforces that the policy is actually achievable.

Consider the sets S−i={(s,b)∣b[i]=0}S_{-i} = \{ (s,b) \mid b[i]=0 \}S−i​={(s,b)∣b[i]=0} and S+i={(s,b)∣b[i]=1}, S_{+i} = \{(s,b) \mid b[i] = 1 \}, S+i​={(s,b)∣b[i]=1}, i.e., the sets of state where TiT_iTi​ has not and has already been visited.

Observe that along every path, one transitions either zero or one time from S−iS_{-i}S−i​ to S+iS_{+i}S+i​. Thus, the expected number of such transitions coincides with the probability to go from S−iS_{-i}S−i​ to S+iS_{+i}S+i​. As one starts in S−iS_{-i}S−i​ (the initial state is not part of TiT_iTi​ by assumption), the probability to go from S−iS_{-i}S−i​ to S+iS_{+i}S+i​ is the same as the probability to reach S+iS_{+i}S+i​, which is the same as the probability to reach a TiT_iTi​ state. for all i≤m∑s∈S−i∑a∑s′∈S+iδ(s,a,s′)⋅ys,a≥λi.\text{for all } i \leq m \sum_{s \in S_{-i}}\sum_{a}\sum_{s' \in S_{+i}} \delta(s,a,s')\cdot y_{s,a} \geq \lambda_i.for all i≤ms∈S−i​∑​a∑​s′∈S+i​∑​δ(s,a,s′)⋅ys,a​≥λi​.

1.4.3Computing Pareto curves via weighted reachabilitydiscuss!¶

We now turn our attention to approximating the Pareto curve. We obtain our approximation by computing a subset of the Pareto-optimal policies. Clearly, the convex and downward closure of the points achieved by these policies is an underapproximation. From the fact that the policies we compute are indeed Pareto-optimal, we also obtain a set of unachievable points. The complement of these unachievable points are then an overapproximation of the set of achievable points. As the achievable points can be represented by finitely many vertices, the algorithm we present also terminates for any precision ϵ\epsilonϵ.

More specifically, the key theorem to the approach is the following:

Theorem 6

Given w⃗∈[0,1]m\vec{w} \in [0,1]^mw∈[0,1]m and

π∈arg⁡max⁡π′∑wiPrπ′(◊Ti).\pi \in \arg\max_{\pi'} \sum w_i \pr_{\pi'}(\lozenge T_i).π∈argπ′max​∑wi​Prπ′​(◊Ti​).

Then:

p⃗=(Prπ(◊T1),…Prπ(◊Tm))\vec{p} = (\pr_\pi(\lozenge T_1), \dots \pr_\pi(\lozenge T_m))p​=(Prπ​(◊T1​),…Prπ​(◊Tm​))

is on the boundary of the achievable points. For wi∈(0,1]mw_i \in (0,1]^mwi​∈(0,1]m, the point p⃗\vec{p}p​ is Pareto-optimal.

Clearly, p⃗\vec{p}p​ is achievable by π\piπ. The argument that it is also Pareto optimal (for almost all www) follows from the fact that every point that dominates ppp yields a higher weighted reachability. Assume that one of those points would be achievable by policy π^\hat{\pi}π^: Then π^\hat{\pi}π^ demonstrates that π\piπ is not optimal w.r.t. weighted reachability, which is a contradiction to the definition.

With this theorem, the idea is now to iteratively explore different weight vectors. The theorem above ensures the soundness. Completeness of the algorithm relies on the fact that there are only finitely many policies, but also requires carefully selecting the weight vectors. In particular, while every weight vector different to the previous weight vectors sharpens the overapproximation, we need to be careful to ensure that we find all vertices in finite time. However, if we pick the weight vectors orthogonal to one of the existing faces of the Pareto curve, we only need as many iterations as the number of faces + number of vertices of the exact Pareto curve. The example below also demonstrates this way of picking weight vectors.

_ = explore_pareto(mdp, ["red", "blue"], [(1.0, 0.0), (0.0, 1.0)], figsize=(2, 2), legend="outside")

We now see that the convex hull is formed, in particular, points between two achievable points must also be achievable.

Next, we take a weight vector (0.5,0.9)(0.5, 0.9)(0.5,0.9) orthogonal to the current face between the two Pareto-optimal points:

_ = explore_pareto(mdp, ["red", "blue"], [(1.0, 0.0), (0.0, 1.0), (0.5, 0.9)], figsize=(2, 2), legend="outside")

This yields one more Pareto optimal point.

By adding two more weight vectors, we can prove that there are no further achievable points:

_ = explore_pareto(mdp, ["red", "blue"], [(1.0, 0.0), (0.0, 1.0), (0.5, 0.9), (0.1, 0.35), (0.4, 0.55)], figsize=(2, 2), legend="outside")
Remark 2 (On computing weighted reachability)

The weighted reachability query can be expressed as a total (undiscounted) reward query on the unfolding. Specifically, you get reward wiw_iwi​ for every transition between an S−iS_{-i}S−i​ and S+iS_{+i}S+i​, using the earlier definitions. While the total reward in general is infinite, it is not if the reward collectible in every MEC is zero. As the reward, by construction, is only awarded upon the first entry of some target set, we can only finitely often pick up reward. Therefore, the total reward is finite and computable via all standard approaches, see Quatmann (2023, Section 4.1.3).
